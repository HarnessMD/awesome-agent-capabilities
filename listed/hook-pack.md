# Hook packs: listed, not reviewed by us

12 items, found in public directories and listed as written there. Nobody here has opened these; read the source before you install one. The reviewed ones are in the [README](../README.md).

## Developer tools

- [beyondcode/claude-hooks-sdk](https://github.com/beyondcode/claude-hooks-sdk): A PHP SDK for building Claude Code hooks. Made by beyondcode.
- [cchooks](https://github.com/GowayLee/cchooks): A Python SDK for claude-code hooks. Made by GowayLee.
- [claudekit](https://github.com/carlrannaberg/claudekit): A toolkit of custom commands, hooks, and utilities for Claude Code. Made by carlrannaberg. Works with Claude Code.
- [claudio](https://github.com/ctoth/claudio): Hook based audio feedback for Claude Code and OpenAI Codex CLI. Made by ctoth. Works with Claude Code, Codex.
- [decider/claude-hooks](https://github.com/decider/claude-hooks): Comprehensive hooks for Claude Code to enforce clean code practices and automate workflows. Made by decider.
- [dependency-license-checker Hook](https://github.com/github/awesome-copilot/tree/main/hooks/dependency-license-checker): Scans package manifests (package.json, Cargo.toml, go.mod) post tool execution to reject incompatible licenses. Made by Awesome Copilot. Works with Claude Code, GitHub Copilot.
- [ralph-loop Hooks](https://github.com/anthropics/claude-plugins-official/tree/main/plugins/ralph-loop/hooks): Intercepts Stop lifecycle event using stop hook.sh to keep agent working continuously until completion condition is met. Made by Anthropic. Works with Claude Code.
- [security-guidance Hooks](https://github.com/anthropics/claude-plugins-official/tree/main/plugins/security-guidance/hooks): Multi stage security gating: SessionStart verifies SDK, UserPromptSubmit scans prompts, PostToolUse warns on dangerous edits, Stop triggers diff review. Made by Anthropic / David Dworken. Works with Claude Code.
- [session-auto-commit Hook](https://github.com/github/awesome-copilot/tree/main/hooks/session-auto-commit): Listens on Stop hook event to automatically generate conventional commit messages for clean incremental work. Made by Awesome Copilot. Works with Claude Code, GitHub Copilot.

## Monitoring and errors

- [hooks multi agent observability](https://github.com/disler/claude-code-hooks-multi-agent-observability): Real time monitoring for Claude Code agents through simple hook event tracking. Made by disler. Works with Claude Code.

## Security

- [secrets-scanner Hook](https://github.com/github/awesome-copilot/tree/main/hooks/secrets-scanner): Inspects file modifications in PostToolUse or pre-commit hooks to block staging private API tokens or.env files. Made by Awesome Copilot. Works with Claude Code, GitHub Copilot.
- [tool-guardian Hook](https://github.com/github/awesome-copilot/tree/main/hooks/tool-guardian): Enforces sandbox policies on PreToolUse, blocking destructive bash operations like rm -rf / or unauthorized network egress. Made by Awesome Copilot. Works with Claude Code, GitHub Copilot.
