- [tldr](https://github.com/tldr-pages/tldr): Short command help agents can read. Made by tldr-pages. Works with any engine.
- [Tunnelmole](https://github.com/robbie-cahill/tunnelmole-client): Free, open source HTTP tunneling client creating public URLs for local services and agent dashboards. Made by robbie-cahill.
